# Contrato — README con inventario de un directorio de primer nivel (D-06; R-06)

Lo que `tests/docs/readmes.test.ts` exige a cada `README.md` de la lista de directorios. Es la
convención que ADR-032 registra.

## Forma

```markdown
# <directorio>/ — <una línea que dice para qué existe>

<uno o dos párrafos: qué es fuente y qué es derivado; quién entra acá y cuándo>

## Inventario

| Entrada         | Qué es                             | Fuente o derivado | Quién lo lee                 | Verificación      |
| --------------- | ---------------------------------- | ----------------- | ---------------------------- | ----------------- |
| `openapi.yaml`  | raíz del contrato                  | fuente            | bundle, servidor, generación | `contract:check`  |
| `components/`   | esquemas, parámetros, respuestas…  | fuente            | bundle                       | Redocly, Spectral |
| `dist/`         | bundle derivado (ignorado por git) | derivado          | tipos, docs, Schemathesis    | no se commitea    |
| `NNN-<nombre>/` | una feature (spec, plan, tareas)   | fuente            | agentes, spec-kit            | `check:markers`   |

## <secciones propias del directorio: convenciones, cómo agregar, extensiones…>
```

Reglas que la prueba verifica:

1. Existe `README.md` en cada directorio de la lista (R-06) y en todo directorio de primer nivel
   nuevo que no esté en las exclusiones globales.
2. La sección `## Inventario` contiene una tabla; la primera celda de cada fila es una entrada
   entre comillas de código: `archivo` o `directorio/`. Las cuatro columnas fijas existen con
   esos encabezados; las columnas propias del directorio (tabla de R-06) también.
3. Cada entrada de primer nivel del directorio (archivos y subdirectorios, incluidos los
   ocultos, excluidos los de la lista del directorio y los globales) tiene su fila **o** encaja
   en una fila patrón (`<…>` es comodín de un segmento; `NNN` de tres dígitos). Cada fila que no
   es patrón nombra algo que existe. Faltantes y sobrantes se listan en el mensaje de fallo.
4. Ninguna celda ni párrafo del README lleva una cifra de estado (`\d+ (archivos|reglas|pruebas|operaciones|términos)`).
5. Para `contracts/`: además, la sección `## Extensiones` tiene una tabla con columnas `Extensión`,
   `Dónde`, `Forma`, `Regla`, `Consumidor`, y el conjunto de la primera columna es igual al de
   las claves `x-*` presentes en `contracts/**/*.yaml` (fuente, no `dist/`).

## Cabeceras (misma suite)

| Directorio         | Regla                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| `generated/*`      | primera línea `// GENERATED by scripts/<x>.mjs from <fuente> — DO NOT EDIT BY HAND`; `<x>` existe |
| `patches/*.patch`  | comentarios iniciales con `# Fix:` (referencia al upstream) y `# Retire:` (condición)             |
| `scripts/**/*.mjs` | la primera línea que no es shebang empieza con `//`                                               |
