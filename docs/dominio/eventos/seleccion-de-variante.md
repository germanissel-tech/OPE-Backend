# selección de variante -> `variant_selected`

> interacción con el selector de variante

Atributo propio: `selectedVariantId`.

Distinta de [interacción con selector de variante](interaccion-con-selector-de-variante.md): tocar el
control es intención, elegir una variante es un hecho que resuelve contra el catálogo. Las reglas de
la política de decisión las usan con umbrales distintos.
