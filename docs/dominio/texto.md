# texto -> `text`

> Cada texto se publica solo, con una versión inmutable por clave acuñada por OPE.

Lo que OPE dice para una clave —familia, valor de atributo, idioma— en una capa: la base, o la de un
merchant. Es el **texto curado** visto desde el panel que lo publica: la misma prosa, revisada por una
persona (constitución VIII), pero con una clave, una capa y un historial. En la API, `texts` es el
recurso que se publica y cuyo historial se lee; lo que una persona ve sigue siendo el texto curado de
la versión que la intervención estampa.
