# escalera del incentivo -> `incentive ladder`

> Resolver la barrera con el menor costo de margen posible: **información → reaseguro → reducción de incertidumbre → evidencia → incentivo.**

El orden de los escalones (`STEPS`) en que se recorren los candidatos de una barrera: se elige
el más bajo que la resuelve; el abandono de carrito que confirma una barrera habilita el
siguiente (D-B); con barrera de precio y la política habilitándolo, el incentivo entra directo.
`uncertainty` existe en el vocabulario sin candidatos hasta el catálogo de mensajes.
