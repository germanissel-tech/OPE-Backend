# Constitución de prueba

- Las barreras son `fit`, `price` y `returns`; el estado viaja como `ATTRIBUTED_ORDER`.
- Todo error es `ledger-unavailable` o similar; la ruta es `/v1/orders`; el comando `npm run x`.
- Los flags `--strict`, la propiedad `a.b`, `Result<T, E>` y `x: y` no se juzgan; `DECIDIDO` sí.
